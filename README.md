# СИСТЕМА Web

Устанавливаемое PWA для развития в реальной жизни: 248 заданий, ежедневные цели, уровни, личные задачи, недельная цель, дневник, цепочки и 72 ступени достижений.

## Локальный запуск

```bash
npm ci
npm run dev
```

## Проверка и сборка

```bash
npm run lint
npm run test:browser
npm run build
```

Браузерный тест использует Chromium (`npx playwright install chromium`) и проверяет desktop/mobile, сохранения, офлайн-режим и основные сценарии.

## GitHub Pages

Workflow `.github/workflows/deploy.yml` собирает `dist` и публикует его при каждом push в `main`. В настройках репозитория Pages → Source должен быть выбран GitHub Actions.

Прогресс хранится локально в `localStorage`. Синхронизации между устройствами и нативными EXE/APK нет; для ручного переноса предусмотрены экспорт и импорт JSON. На iPhone установка выполняется через Safari → «Поделиться» → «Добавить на экран “Домой”».
